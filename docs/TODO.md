## Source colour targets (new feature, one line per platform)

The idea (owner, 2026-11-25): the chain stays as it is; a step at its head turns the colours of the source into what the device it came from would have shown, as accurately as the sources allow, before the beam and the mask render it. **Built:** the slot `target` (`source_colour_target`, per-game profile fields `colour_target`, `colour_variant`), four transform kinds (`matrix`, `curve`, `palette`, `dac`), the data-file format with a provenance per value (`presets/targets/`, `src/targets.rs`), the oracle (`crt_model::target`) and a GPU test per target, the 5-bit codes recovered exactly from expanded pixels. **The research:** every platform is audited in `QUESTIONS.md` ("Audit of the colour targets": data, verdict, transform kind, licence), seven independent audits; no target ships without a named source for its numbers. Licence rule: numbers and measurements with attribution, never code or tables from GPL, LGPL or AGPL repositories.
