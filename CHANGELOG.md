# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html) (while below 1.0.0, a minor bump may break things).

Every change goes under `## [Unreleased]` as it is made. Publishing renames that section to the new version and date (see `ENV.md`).

## [Unreleased]

### Added
- Automatic beam limiting and raster breathing (`abl` slot after `gun`, `shaders/abl.comp` and `shaders/reduce.comp`, `params/abl.toml`, T-35): the frame's mean beam current (GPU reduction, FP32) is low-passed on real frame times (`abl_tau_s`, default 0.1667 s) and lowers the beam current of the next frame above `abl_threshold_ma` (1.4 mA) with g = 1 / (1 + k max(0, I - I_th)), k set by `abl_full_white_ratio` (0.5); raster breathing `raster_scale` = 1 + `abl_breathing` (APL - `abl_breathing_ref`), computed for the geometry stage (T-37); `abl_probe` diagnostic. Off by default (exact identity). Oracle `crt_model::abl`.
- Output transform (`encode` stage): tube primaries and white to sRGB colour matrix (`output_match_srgb`), soft shoulder (`output_knee`), clip counters (`Renderer::clip_counts`), and a final 1 LSB dither (`output_dither`: off, ordered, noise). `crt-model::output` is the f64 oracle; `crt-model` is now a regular dependency of `ultimatecrt`.
- GPU timestamps per stage (T-21): Vulkan timestamp queries (one pool per frame in flight, read without stalling when the slot is reused, `timestampPeriod` and `timestampValidBits` honoured) around `upload`, `decode`, every chain slot, `encode` and the whole frame. `--stats` prints a per-stage GPU line, the `--log` CSV gets `gpu_frame_ms` and `gpu_<segment>_ms` columns appended after the existing ones, and `Renderer` and `Headless` expose `FrameTimings` (latest frame, per-second mean). A device without timestamp support turns it off with a message.
- Gun law and white balance (`gun` slot, `shaders/gun.comp`, `params/gun.toml`): `gun_law` power (default, 2.4), gog (contrast, brightness, per-gun cutoff and drive), bt1886 (Lw, Lb) and bt1886_annex1; optional white retune relative to the tube white, to the target `gun_retune_white_xy` (`gun_white_balance`, default off; gains (1, 1, 1) when the target is the tube white); the `srgb` source mode inverts the nominal curve of the active law and `gun_gamma` is clamped to >= 0.1; a disabled `gun` slot shows V as linear light, which is lighter than the gun-on picture. Oracle `crt_model::gun`.
- Video amplifier (`amp` slot, `shaders/amp.comp`, `params/amp.toml`): Gaussian low-pass of the drive voltage before the gun law (`amp_bandwidth_mhz`, `amp_pixel_clock_mhz`), asymmetric rise/fall (`amp_fall_rise_ratio`), optional peaking (`amp_peaking_gain`, `amp_peaking_mhz`), K sub-samples per native pixel each holding the exact box mean of the amplifier output, clamped to the local input range (slew limiter); the defaults are an exact zero-order hold. Oracle `crt_model::beam::gaussian_step_box_mean`.
- Gun law and white balance (`gun` slot, `shaders/gun.comp`, `params/gun.toml`): `gun_law` power (default, 2.4), gog (contrast, brightness, per-gun cutoff and drive), bt1886 (Lw, Lb) and bt1886_annex1; optional white balance from the tube primaries and white xy (`gun_white_balance`, default off). Oracle `crt_model::gun`.
- `scripts/poll-foreground.ps1`: polls the foreground window every 100 ms and logs each change to a CSV (title, pid, executable, is-source), with a summary and a `-SelfTest` switch.
- `--log <file.csv>`: per-second diagnostics (capture and render fps, min/max/p99 intervals, gaps over 50 ms, foreground-window changes, "foreground is the source" flag) and a summary at exit.
- `pixel-demo`: demo source window with a procedural NES-style scene, a test card and optional PNG display, at any source resolution and integer scale.
- `ultimatecrt`: window capture (Windows.Graphics.Capture, client area only, CPU copy) and Vulkan 1.3 output through a passthrough GLSL pass, in a windowed or fullscreen non-activating window. Ctrl+Alt+Q always quits.
- Source integer scaling: `--crop`, `--divisor` and automatic detection (x1 detected as native). Flat frames (a black boot screen) are not counted by the detector.
- `--version` flag on both programs, single workspace version.
- `ultimatecrt --help` prints every option. A bad numeric option value names the flag.
- Pinned toolchain (`rust-toolchain.toml`) and formatting rules (`rustfmt.toml`).
- `scripts/package.ps1` (fmt, clippy, build, tests, licence check, zip with checksum and commit record) and `scripts/release.ps1` (GitHub release from the changelog section, with safety checks).
- Documents: `CLAUDE.md`, `CRT.md`, `QUESTIONS.md`, `ARCHITECTURE.md`, `DESIGN.md`, `ENV.md`, `README.md`.
- Declarative parameter table `params/*.toml` (units, soft ranges, confidence tags, sources) and the `paramgen` build-time generator of the Rust `Params` struct, its metadata and std140 bytes, and the matching GLSL uniform block. First entries: `exposure` and the tube primaries and white point.
- Headless renderer (offscreen RGBA16F/RGBA32F render and readback, no window) and GPU tests run by `cargo test`, failing on any validation message; `UCRT_REQUIRE_GPU=1` makes a missing GPU or validation layer a failure instead of a skip.
- `--validation` prints the layer's messages on stderr through a debug messenger, and names the missing layer when the Vulkan SDK is not installed.
- Pipeline core: an FP16 `decode` stage (compute, native raster read at block centres) and an `encode` stage (explicit host EOTF, black surround around the tube rectangle), two frames in flight with per-frame uniform and staging buffers, images reallocated on source or native size change. Headless identity tests: all 256 codes per channel come back exact through the FP16 raster, FP16 subnormals kept.
- Source decode and tube placement (T-30): parameters `source_eotf` (`drive_voltage` default, or `srgb`: decoded to linear light, then drive voltage = L^(1/tube gamma)), `raster_aspect` (`par` default or `fill_tube`), `source_par`, `line_multiplier` (1 or 2), and the tube `tube_visible_height_mm` (290), `tube_aspect` (4:3) and `tube_height_fraction`. The CPU now fills `px_per_mm` and `line_pitch_mm` of the frame constants (PVM-20M4U class on 2560x1440: 4.966 px/mm, 1.208 mm line pitch). With the defaults the picture is placed exactly as before.
- Beam, vertical scanline profile: each native row is drawn as a scanline whose Gaussian spot (plus an optional wide tail) is integrated over every host pixel, with the flat-field brightness independent of the spot width. New parameters `beam_fwhm_mid_mm` (default 0.45 mm), `beam_tail_weight`, `beam_tail_sigma_ratio`. Active once the tube is placed (px per mm and line pitch set); until then the screen stage keeps the nearest-sample copy.
- Mask, aperture grille: every host pixel takes the exact area average of the R, G and B phosphor stripes it covers (pitch, stripe fill and edge softness in physical units), normalised so that flat white keeps its brightness, with optional damper-wire shadows. Below 3 host pixels per triad the mask is averaged out by default (no host-grid moire); `mask_tier` can force either behaviour. New parameters `mask_enabled`, `mask_type` (slot mask and delta are drawn as a grille for now), `mask_pitch_mm` (default 0.31 mm), `mask_stripe_fill`, `mask_edge_softness`, `mask_damper_count` (default 0), `mask_damper_width_mm`, `mask_damper_edge_mm`, `mask_tier`, and, declared for later, `mask_slot_period`, `mask_slot_bridge`, `mask_dot_fill`.
- Beam, horizontal spot and spot growth (T-36b): along each scanline the amp samples are blurred by the same round spot and integrated over every host pixel (energy per source pixel conserved, flat fields unchanged), and the spot widens with each gun's beam current, FWHM^2 = d0^2 + k I^(2n). New parameters `beam_fwhm_peak_mm` (default 0.8 mm, PVM-20M4U) and `beam_growth_exponent` (default 0.5); `beam_fwhm_mid_mm` is the width at mid drive (beam current 0.5^2.4). Per-channel convergence hook in `beam.glsl`, zero until T-37.
- Phosphor persistence (`phosphor` slot, `shaders/phosphor.comp`, `params/phosphor.toml`, T-41): optional frame-to-frame afterglow from the measured P22 decay (Kuhn 2002): a bright frame leaves a green and blue trail of about 5.4 / 4.7 % of its light one frame later at 60 Hz, then about 3 % and 2 %, red none; a static picture keeps its brightness. New parameters `phosphor_persistence` (default off: the picture passes unchanged), `phosphor_frame_rate_hz` (60, the output refresh rate) and `phosphor_tail_strength_rgb` (0.07 to 1). The afterglow is cleared on a source size change and on a new capture session. Oracle `crt_model::phosphor::DecayFit::frame_feedback`.
- Geometry and convergence (T-37, `shaders/include/geometry.glsl`, `params/geometry.toml`): optional curved faceplate (`geometry_curvature` flat, spherical or cylindrical, `geometry_radius_mm`, `geometry_eye_distance_mm`; the raster lies on the surface uniform in arc length), residual pincushion/barrel, trapezoid and rotation, overscan per axis, and per-channel misconvergence (static dx, dy in mm plus a radial term growing toward the corners). ABL raster breathing (`abl_breathing`) now resizes the picture about the tube centre. The mask stays fixed on the tube. Every default is the identity: the picture is unchanged. The tube image carries a margin around the raster (`raster_margin`, 4 sigma of the spot at twice the peak current plus the largest misconvergence, limited by the room in the output) where the spot's skirt is drawn instead of cut; the live output adds it whenever the `screen` slot runs (a bypassed `screen` has no skirt and no margin). The `standard` beam quality keeps its separable fast path for the margin, overscan, `raster_scale` and misconvergence; a curved faceplate, pincushion, trapezoid or rotation makes it fall back to the `reference` evaluation (the cost of `reference`).
- Visible opening (T-37 review): the light of `screen` is clipped to the tube's visible area (`tube_visible_height_mm` x `tube_aspect`) with rounded corners, `geometry_opening_corner_radius_mm` (default 0, square; CRT.md 15 to 40 mm on older tubes): exactly 0 outside, antialiased over one host pixel along a curved outline. Not implemented and deferred (QUESTIONS PHY-11): S-linearity residuals (CRT.md has no residual profile) and refraction through the faceplate (no outer radius or glass thickness per curved tube).

### Changed
- Geometry review follow-ups (T-37): the skirt margin is still evaluated but lies outside the visible opening, so it is black and the picture's outer edge no longer moves with the spot size, overscan or `raster_scale`. Overscan and `raster_scale` keep the spot's size and the misconvergence in mm and dim the picture by the raster's area (1 / (sx sy), the same beam current over a larger raster) instead of magnifying the spot with the raster. `screen` takes `raster_scale` 1 when the `abl` slot does not run in the frame (it read a stale or unwritten state before), and the ABL state starts at `apl_f` = `abl_breathing_ref` while the breathing is on, so the first frame has scale exactly 1. The pincushion inverse takes four fixed-point steps (corner residual at |k| = 0.05 from 0.007 to 0.023 mm down to 0.0006 to 0.0028 mm). The standard-vs-reference beam contract is MAE <= 0.5 % and max <= 4 % of white for any pixel alignment (was 2.5 % max, valid only at the identity alignment).
- Mask tiers per axis with a blend band (T-39c, D-15): the slot mask and the delta mask are also prefiltered vertically when their row period (V / 2, P / 2) is under 2 host px (delta at 3 px per triad: 27 % row ripple before, 0 after; slot defaults: 6.1 % before), with a box of one whole period V or P; the new `mask_tier_blend` (default 0.4 px per triad, 0 = the previous hard switch) narrows the prefilter box continuously from one period to one host pixel across 2.8 to 3.2 px per triad (and the same relative band around 2 px vertically), so the mask fades in instead of snapping from flat to saturated RGB columns at 3.0. The decision is made once per frame on the CPU in f64 (`placement::mask_tiers`, appended `FrameConstants::mask_box_px`, 96 bytes), so the shader and the readouts (`crt_model::mask::readouts` now takes a `TierRule` and reports `axis_tiers`) cannot disagree for pitches on a limit. `Mask::host_value` takes the per-axis tiers.
- Identity stages are skipped (`Stage::is_identity`): a same-domain slot whose stage is an exact identity for the frame's parameters is routed around like a disabled slot (no pass, no image, no barrier; its timing segment is absent). `phosphor` with persistence and saturation off no longer copies the whole tube image (16 B per texel), and `abl` with the limiter, the breathing and the probe off records neither the copy nor the reduce pass; the output is bit for bit the same, and switching a feature on again starts as the off to on transition did. With the breathing on and the limiter off `abl` still runs (the geometry reads `raster_scale` from its state). `Headless` gains `last_chain_passes`, `last_skipped_slots` and `render_burst_params`; the `abl` state clear now waits for earlier reads of the state buffer.
- The aperture grille, slot mask and delta lattices are centred on the tube centre (both axes) instead of starting at the picture's top-left corner (T-37): the mask no longer shifts when the picture width changes (PAR, raster aspect) or when the skirt margin is added. The phase reduction stays exact (integer arithmetic on the doubled f32 period).
- FP16 stage stores round to nearest, ties to even, on every device (`round_f16` in `shaders/include/common.glsl`, applied at every `imageStore` of `decode`, `resample`, `amp`, `gun`, `abl` and `screen`): the Vulkan spec leaves the float to FP16 rounding to the implementation and this NVIDIA driver truncated (bias -2^-10 to 0 per store, about -0.15 to -0.2 % after the chain). The 8-bit identity budget drops from 0.4968 to 0.311 of a code on an RGBA16F target (0.186 on an 8-bit target), the stage tests use the symmetric half-ulp window, and `gpu_fp16_store` checks the stores bit for bit against a CPU reference.
- A fullscreen output now refuses to start when the Ctrl+Alt+Q hotkey cannot be registered, and an unknown `--monitor` index is an error (it used to fall back to a default rectangle).
- The output window releases its hotkey and window when dropped.
- The swapchain warns when it has to use a format other than `B8G8R8A8_UNORM`.
- The Esc hint is no longer printed for a `--no-activate` output.
- The output is no longer a plain copy: captured codes are linearised with a pure 2.4 power law (stand-in for the gun law until it exists, SRC-5 default) and encoded for a pure 2.2 host display (COL-3 default), so the picture is slightly darker than the source. GPU tests now also report shader-access hazards (synchronization validation with `syncval_shader_accesses_heuristic`).
